# V2 Phase 1 Visual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** V2 Phase 1 look: semaphore circle pins with live minutes, duel verdict card with marked winner, «Espera X min» semantics — zero decision-logic changes.

**Architecture:** `map.js` gains a pure `pinStyle()` (tested) + Leaflet `divIcon` rendering; `map.html` gains the duel CSS + spinner; `ui.js` render paths output the new markup, clear stale numbers on recalc, and rename user-visible «Bus N min» to «Espera N min». Palette: walk green `#16a34a`, wait amber `#d97706`, no-data gray `#9ca3af`, you-blue `#1a73e8`. Pins are amber-with-data / gray-without (green is reserved for the walk side — no destination means no verdict, so pins never claim green).

**Tech Stack:** Vanilla CSS + Leaflet 1.9.4 `divIcon`, existing ESM modules, `node --test`, Docker manual verification.

## Global Constraints

- No npm deps, no build step, no framework.
- `decide()`/fallback hierarchy/AppState/debounce/race-guard untouched — visual layer only.
- Winner never marked by color alone: frame + ✓ + typographic hierarchy.
- Calculating state hides previous numbers (never decide on stale data).
- Spanish UI copy; user-visible wait times read «Espera X min», never «Bus X min».
- Leaflet draws; no business logic in `map.js` beyond the pure `pinStyle()`.

```js
export function pinStyle(arrivals, focused) {
  if (arrivals.length === 0) return { label: '—', color: 'gray', scale: 1, halo: false };
  const minutes = Math.min(...arrivals.map((a) => a.minutes));
  return { label: `${minutes}′`, color: 'amber', scale: focused ? 1.25 : 1, halo: focused };
}

const COLORS = { amber: '#d97706', gray: '#9ca3af' };

function pinIcon(style, name) {
  const size = Math.round(48 * style.scale);
  return L.divIcon({
    className: 'stop-pin',
    html: `<div title="${name}" style="width:${size}px;height:${size}px;border-radius:50%;background:${COLORS[style.color]};color:#fff;font-weight:800;font-size:18px;display:flex;align-items:center;justify-content:center;border:3px solid #fff;box-shadow:0 2px 6px rgba(0,0,0,.3)${style.halo ? ',0 0 0 6px rgba(217,119,6,.35)' : ''}">${style.label}</div>`,
    iconSize: [size, size],
    iconAnchor: [size / 2, size / 2],
  });
}
```
